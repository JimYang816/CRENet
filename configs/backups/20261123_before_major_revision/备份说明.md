# 大改前参数备份（2026-11-23）

本快照记录大改前的项目参数，源码基准为 Git 提交 `efb847c14e97c5fcd0e6c829795b5101b9190ecb`。当前使用的六份配置按原有相对路径保存在 `active/`：两份信道数据配置、三份训练配置和一份统一评测配置。需要恢复时，将 `active/` 下对应文件复制回项目根目录的 `configs/`。

`formal_runs/` 保存正式训练、七算法比较和 A–D 消融的实际运行配置和来源，以及两信道冻结先验参数、NCS1 NMSE 重定标配置和 OAMP-Net2 两信道的训练身份。NCS1 的 `retarget_config.json` 从原重定标记录提取当前目标和来源，OAMP-Net2 的 `effective_identity.json` 从正式训练摘要中的 `identity` 字段提取。历史运行配置中的路径、算法名称和参数保持原样，用于核对已完成实验，不能直接替代 `active/` 中的现行配置。

部分默认值定义在 Python 源码中。对应的完整 Git 跟踪文件快照为 `outputs/experiment/archive/config_provenance_20261123_before_major_revision/source_efb847c.tar.gz`；同一目录还保存服务器正式数据生成验收、来源和训练摘要的原始记录及校验值。这些来源记录和源码归档不纳入 Git。

`backup_manifest.json` 记录配置 JSON 的规范化内容 SHA-256 及源码归档的文件 SHA-256；来源归档中的 `sha256.json` 记录每个原始文件的 SHA-256。本地和服务器的原始配置可能采用不同换行符，规范化 JSON 摘要按内容比较。

本备份不包含数据集或模型权重。服务器数据集此前已删除，训练或评测仍需先恢复或重新生成数据；正式实验权重和报告保留在原有实验目录。
