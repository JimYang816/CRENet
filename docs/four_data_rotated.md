# 固定12 Hz全频带统计时间基4D小实验

本页为历史归档：其全频带载波布局已按用户要求停止用于当前实验。
当前默认原载波协议见`docs/four_data_original_layout.md`；此处入口只允许`--report-only`重画历史结果。

本实验按已确认方案运行：无P的D1–D2–D3–D4，NOF1使用Q_eff=5、L=512，
NCS1使用Q_eff=12、L=224；每D为512导频、256保护、256数据，覆盖整个1024载波。
四D的 `DDZPPPPZ` 图样分别错开0/1/3/5个载波。
原始12 Hz、Q27字典内的统计时间旋转使用独立先验051–055、2/14秒窗口，
冻结后不再用本次测试数据更新。源基与设计检查见 `docs/four_data_design.md`。

## 接收机与比较口径

- 从先验缓存的四个FFT窗口系数相关量拟合当前坐标系的协方差，延迟块宽32、正则化1e-6。
  四个D的错位导频、保护与数据掩码分别建模；未知单位能量QPSK贡献逐D有色ICI协方差。
- 3072个选取观测联合估计一组Q_eff×L系数；接收机输入为实际含噪观测、公开导频、
  掩码、独立冻结先验、已知仿真RF噪声方差和发射归一化增益，不读取参考CSI或数据标签。
  不进行理想补偿、NMSE目标缩放或判决反馈。
- 两种LMMSE复用现有实现。单抽头使用数据载波原始观测与CSI对角线；完整矩阵使用全部接收行，
  按估计CSI消除公开导频后联合检测256个数据符号。
- 正式小实验复用原Q24/L176的30个窗口：固定测试记录011/015/019/023/027/031/035/039/043/047，
  各取2/14/26秒。SNR为0:5:30 dB；新方案每SNR61440比特，原方案122880比特。
  新载荷为原帧各D载荷的前256个QPSK符号，标准RF噪声与原方案相同。
- 新旧两种波形和有效载荷不同，因此比较是完整方案比较，不单独归因于Q或L。
  每个方案的固定CSI同时供两种均衡器使用，共用一条NMSE曲线。

## 发射功率与CSI坐标

先解析计算固定公开导频和独立proper QPSK数据的平均实RF发射能量，计入所有CP及发射插值滤波器，
求得新导频能量，使新旧平均RF发射功率相同。该值不直接套用仅匹配FFT能量时的0.75近似。
随后逐帧用原配对波形的实际RF发射能量作目标，施加标量增益g，验证新旧发射能量相等。
这个功率控制只使用发射端波形，不使用信道或接收标签。

接收机CSI定义为包含g的有效信道，故数据符号仍按单位QPSK检测，公开导频按归一化频域网格表示。
相应系数先验协方差为g²P；通过将估计器的RF方差除以g²，复用原预计算谱，等价于该先验缩放。
均衡器使用实际RF噪声方差。完整参考CSI也按g缩放，仅用于NMSE和物理诊断。
每帧保留旧/新RF能量、增益、功率比和原始误码计数，避免把额外发射能量计作算法收益。

SNR仍由全部四个干净接收FFT窗的平均功率定义。平均NMSE先对所有帧、所有D的完整矩阵相对平方误差求线性均值，
再转dB，计入L之外的能量及时间表示误差。实际物理回放保留符号间泄漏和前端模型误差。

## 2026-11-19 运行结果

服务器使用RTX 4080和代码 `683b6be` 完成两信道各30帧、全部七个SNR。
CPU/CUDA、错位掩码的显式稠密LMMSE、发射功率和原基线测试共13项通过。
取回结果后重新从逐帧数据核对全部误码数、比特数和线性平均NMSE；
60个配对帧的RF发射能量比范围为0.9999999999999996至1.0000000000000004。

解析功率标定给出的每导频能量为0.8090168523，数据符号能量为1；
新旧期望平均实RF发射功率均为0.2823453155（相同离散仿真单位）。
随后逐帧归一化增益范围为0.995551884至1.004886941。
该结果计入CP和发射滤波器，故与仅匹配FFT符号能量时的0.75导频能量近似不同。
