# DPSS-BEM 分组 OMP 接收机诊断

此诊断应用户要求独立比较接收机信道估计器。正式均衡实验仍使用已验收的 compensated CSI；本诊断重新利用相同物理观测、公开 P1/P2 和 D1/D2 跟踪频点计算接收机 CSI，不使用参考辅助补偿、原始 CSI 视图的评测缓存、检查点或特征。

## 估计方法

两种估计器均使用数据集共享的整帧 DPSS 基、736 点延迟支撑、接收噪声参数以及独立先验记录拟合的冻结接收机统计。观测频点为 P1/P2 全部频点和 D1/D2 各 384 个导频及保护频点。未知数据符号不提供给估计器。

- 联合 LMMSE 恢复 `model.h5` 中的冻结观测谱、增益及噪声处理规则，对当前观测重新求解；未知数据引起的 ICI 协方差已包含在其模型中。
- 分组 OMP 以每个延迟上的全部 Q=34 个系数为一组。基于相同独立先验的逐延迟边缘协方差缩放组，按白化相关能量逐次选组，每轮用岭正则联合重拟合所有已选系数。OMP 白化热噪声并使用接收机噪声下限，但没有对未知数据 ICI 的完整相关协方差进行白化；该模型差异属于比较的一部分。

OMP 的组数和岭正则倍数从 `configs/evaluation/dpss_channel_comparison.json` 指定网格中由验证集确定：先在较小组数和多种岭正则倍数的网格中选择，再固定首阶段选中的正则倍数并扩大组数搜索。两个阶段均以全部验证 SNR、帧与 D 块的完整矩阵线性 NMSE 平均值选参，比较两阶段最优结果并冻结到测试集。两条信道执行相同的选择规则。测试时，估计和均衡完成后才读取参考 CSI 和比特，分别计算 NMSE 和 BER。

两种估计器之后均使用相同的完整矩阵 LMMSE 均衡器，保留全部接收频点、数据列、ICI 及完整热噪声协方差。NMSE 是逐 D 块完整矩阵相对平方误差先在线性域平均，再转换为 dB；BER 使用全部测试比特。

## 运行与时间口径

```bash
/home/fay/anaconda3/envs/jimyang/bin/python -m scripts.evaluate.dpss_channel_comparison \
  --device cuda --threads 4 --output outputs/experiment/dpss_bomp_<run_id>
```

实验输出独立于现有主比较和其他 raw 结果。验证与测试逐物理窗口提交完成标记；同一代码、数据、数值环境及配置下可以使用同一命令断点续跑。输入数据和计算代码摘要参与身份检查，拒绝复用不匹配的结果。

估计时间使用 GPU 同步墙钟，包含当前观测的选择、噪声下限计算、白化、组搜索、全部系数拟合和估计系数返回；两方法使用相同微批大小，测试窗口交替先运行两种估计器。初始化和共同均衡时间单独报告，不包含标签、参考 CSI 和指标计算。LMMSE 初始化读取已有冻结谱和增益，OMP 初始化构造并白化导频字典，耗时口径需在比较时说明。

输出包括验证参数选择、完整测试 NMSE–SNR 与 BER–SNR、估计耗时、逐窗口可恢复状态和输入身份。运行结束后应检查参数是否落在搜索网格边界；若是，只能在该网格内解释选型，不能据此推断更大组数或其他正则参数的性能。
