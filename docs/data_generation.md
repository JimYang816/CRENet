# NOF1 / NCS1 数据生成

当前阶段使用 D-D-D-D 帧，先完成原始接收机 CSI 的小样本均衡实验。配置、载波分配、先验和测试记录、指标定义及运行方式见 [四数据符号 LMMSE 小实验](four_data_lmmse.md)。

两信道共用 FFT1024、CP256、提前32点、基带/通带采样率6/96 kHz、载频14 kHz；每个数据符号使用512个数据载波、256个梳状导频、128个带内保护空载波及两侧各64个边缘空载波。DPSS 跨完整四符号帧及循环前缀，半带宽12 Hz、固定 Q=24、延迟支撑L=176。四个符号的导频和保护空载波参与联合估计；估计结果不再使用参考信道或目标 NMSE 进行补偿。

小实验读取独立先验记录并从 WATERMARK 信道重放物理接收链路，在测试记录上同时评测估计 CSI 与理想参考 CSI。参考 CSI 用于评测和独立先验，不参与测试帧估计结果的修改。物理样本保留在服务器的 `outputs/smoke/`，轻量图表与指标可带回本地。

旧的 P-D-D-P 压缩数据与其检查点、特征和评测缓存不适用于新的帧。历史 P-D-D-P 生成器的无补偿格式使用独立的 `watermark-pddp-compact-raw-v3` 协议，不读取或改写旧补偿格式。当前小实验尚未生成完整 D-D-D-D 训练/验证/测试数据集；在生成并验收新数据、适配四个数据符号前，不应运行学习型算法的正式训练或对比。
