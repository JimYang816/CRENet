# 固定12 Hz、无P、4D新方案的高SNR退化复核

## 结论与范围

已用新方案保存的实际接收观测完成NOF1、NCS1各30帧、0:5:30 dB的因果复核。
**主因是CSI估计器的观测统计模型没有包含BEM表示残差，尤其是公开导频的响应残差。**
热噪声随SNR下降后，估计器增大弱观测模态的逆增益，把这部分持续存在的失配拟合到CSI中。
NOF1以导频残差为主；NCS1还存在明显的数据表示残差。
新方案的满列秩和较小的最优投影误差，并不能保证使用失配协方差的实际LMMSE估计单调改善。

未发现本次复核所覆盖的复数基变换、错位掩码、噪声缩放或矩阵求解存在实现错误。
延迟分块、可分离先验确实造成空间内数据ICI协方差偏差，但替换该协方差几乎不能改善结果，
因此不能把它当成本次退化的主要原因。NOF1物理符号间泄漏是次要因素；
检测端仅按热噪声正则化也有遗漏，但单独增大检测正则化的效果远小于修正CSI估计。

原实验目录和原始指标不变，结果另存于
`outputs/experiment/four_data_rotated_full_band_20261119/covariance_audit/`。
因果计算使用服务器RTX 4080、complex128和提交`2ee7151`；图表功能随后补充。
本次仅增加诊断与验证，没有将任何诊断对照替换为默认接收机。

## 估计器实际建模的内容

归一化掉已知发射增益g后，令c为Q_eff×L系数，A为四D公开导频的联合观测矩阵。
当前增益为

\[
K_\sigma=P_b A^H\left(A P_b A^H+R_{D,\mathcal B}
              +(\sigma_{\rm RF}^2+\epsilon)R_n\right)^{-1}.
\]

P_b来自独立先验记录，延迟分块宽32，块内使用时间与延迟可分离的二阶矩；
R_D仅包含该有限BEM空间内的未知单位QPSK数据ICI。R_n为单位实RF噪声经实际接收滤波后的有色协方差；
epsilon为白化协方差平均特征值的1e-6倍。

估计器没有显式包括以下观测项及其与目标系数的交叉统计：

- e_p：完整参考信道与Q_eff/L联合投影信道，对同一公开导频产生的响应差；
- e_d：上述两信道对同一实际数据产生的响应差；
- e_phys：实际RF回放与完整逐D循环参考模型之间的差，包含符号间泄漏和前端剩余偏差。

这三个量与当前参考CSI的定义一致，满足逐帧恒等式

\[
y=A c^\star+H_D^\star d+e_p+e_d+e_{\rm phys}+n.
\]

Q_eff/L投影使用冻结时间基；其四个FFT窗联合Gram为单位阵。
所有参考CSI和真实数据仅用于诊断构造上述残差，不参与原接收机或非oracle对照。
移除残差的对照只修改CSI估计器的观测；BER始终在原始含噪接收数据上检测，
没有把被清理的观测用于均衡检测。

## 热噪声、归一化与数值实现排查

1. 用有限长RF降采样算子D独立构造4DD^T，再转换到FFT域。
   与记录的R_n的相对Frobenius误差在两信道均为5.69e-16；
   单位RF噪声增益均为0.2407114517730546，四D间的噪声协方差为0。
   实RF噪声的伪协方差相对范数约7.47e-6；本次复线性估计的MSE传播使用常规协方差即为精确值。
2. 在0/20/30 dB，将谱分解实现与3072维原始协方差的直接求解比较，
   系数相对误差最大4.06e-12。实际两信道全部保存系数及30 dB误码数均复现；
   重新计算的所有SNR平均NMSE与原报告相差小于1e-10 dB。
3. 发射g包含在有效CSI中，对应先验g²P与估计器使用RF方差/g²等价；
   对y、CSI同时除g后重新估计，结果一致。独立小规模检查覆盖复数旋转时间基、
   四D不同观测行、显式数据载波ICI累加和g²先验缩放。
4. 将真实干净观测通过每个SNR的估计增益，并解析传播完整热噪声协方差，
   得到条件于该信道和载荷、对全部热噪声实现平均的精确预期NMSE。
   其20→30 dB仍从NOF1 −12.7353升至−11.7080 dB，
   NCS1 −6.9240升至−6.3337 dB。因此回升不是30帧单次噪声实现的偶然波动。
   同期热噪声单项对CSI误差的贡献下降，回升发生在干净输入产生的估计偏差中。

## 数据干扰协方差与检测端

将同一10个独立先验的投影信道逐数据列构造成经验R_D，与当前块可分离模型比较，
空间内协方差相对Frobenius差约NOF1 36.26%、NCS1 34.27%。
两者空间内总干扰功率迹却相近，说明近似主要改变干扰方向。
同时，完整物理自符号数据响应的干扰迹分别约为当前模型的1.94倍和1.28倍，
这部分比较尚不计跨符号数据泄漏。

仅把R_D替换为这些独立先验的经验空间内协方差，保持目标P、A、数值ridge不变，
两信道仍回升，30 dB还稍差。因而空间内协方差形状近似不是当前主因；
必须处理被有限时间基和延迟支撑遗漏的响应，而不只是重算已包含的ICI。

完整矩阵检测器当前在按估计CSI消除导频后，仅以sigma_RF² R_n建模剩余扰动；
没有显式计入Delta H_D d、Delta H_P p和物理残差。
固定原30 dB CSI，只将检测RF方差改为该帧20 dB的值：
NOF1完整矩阵BER仅4.4775%→4.4531%，NCS1仅7.4626%→7.4300%。
相同操作单抽头硬判决完全不变，符合其正实数分母不改变QPSK象限的实现。
这将检测器的过强置信与CSI估计器失配区分开：当前收益主要来自改善CSI估计。

## 无测试CSI参与的保守修正对照

从原独立先验051–055的10个窗口计算固定公开导频的实际物理响应与BEM响应残差，
以及完整自符号数据列与BEM数据列的残差迹。令

\[
\delta=\frac{\operatorname{mean}_{\rm prior}\|e_p\|^2+
          \operatorname{mean}_{\rm prior}\operatorname{tr}(R_{\Delta D})}
         {\operatorname{tr}(R_{n,\mathrm{selected}})}.
\]

NOF1得到delta=45764.17414044211，NCS1为1.2868244205631843e-5，
单位与各自信道的RF方差一致。两信道物理幅度标度差异很大，不应直接比较这两个数。
它是从独立先验校准的标量迹近似，未使用测试参考CSI、测试误码数或测试最优SNR选择参数。
用sigma_RF²+delta替代CSI估计器中的sigma_RF²，检测端仍用实际RF噪声方差，
本次全部七个SNR的NMSE均持续下降，30 dB误码率如上表。

该对照证明遗漏的非热噪声扰动需要保留正则化，而不是将热噪声真实方差人为改大作为新定义。
另一个固定20 dB的下限只作为事后机理诊断，不作为可部署参数选择方案。
先验标量下限仍不是完整有色残差模型：导频残差有结构，并可能与目标系数相关；
正式修正宜在独立先验/验证数据上同时标定完整观测协方差和目标—观测交叉协方差，
包含导频表示残差、空间外数据ICI，NOF1还应包含跨符号项。
修正后需按固定测试集重跑BER-SNR和NMSE-SNR，并单独报告有效吞吐量。
